# 华人资本在美 AI/科技 Sourcing Playbook（2012–2024）

> 内部 sourcing 参考。研究问题：过去十几年硅谷里，华人资本"够得着"的好项目分布在哪里？
> 研究方法：多源公开数据（Crunchbase / PitchBook / CB Insights 公开层 + Wikipedia / TechCrunch / 公司新闻稿 / 律所 memo）+ 对抗式交叉核验。
> 判断纪律：**ex-ante**（当年识别得出 + 当年进得去），不是今天回头看；**带分母**（同赛道华人投了 vs 漏了），避免幸存者偏差。

---

## 0. 判断框架（两轴 + 三类）

**两轴打标签：**
- **access（可投性）**：华人资本在当年（ex-ante）进不进得去。受三因素约束：① 监管（CFIUS，见 §1）；② 轮次是否对外开放（是否被顶级基金 club 锁死）；③ 创始人是否主动排斥中资。
- **outcome（结果）**：项目最后做得好不好（独角兽 / 大额退出 / 大轮次）。

**三类：**
| 类别 | 定义 | sourcing 含义 |
|---|---|---|
| **A 被错过的华人项目** | 好 + 进得去 + 华人没（充分）投 | 华人创始人，本应是天然主场，却漏了 → **核心改进区** |
| **B 可投的白人项目** | 好 + 进得去 + 创始人非华裔 | 早期对外开放、华人本可进 → **机会扩展区** |
| **C club deal** | 好 + 进不去 | 标排除原因（监管/锁额/创始人排斥）+ 标二级市场是否可买 |

**A 类再分三因（只有"没看到""拿不到额度"算 sourcing 问题）：**
- 没看到（deal flow 盲区）→ sourcing 问题 ✅
- 看到了 pass 了（判断问题）→ 不算 sourcing 问题 ❌
- 拿不到额度（access 问题）→ sourcing 问题 ✅

## 1. 可投性分期（监管约束 · ex-ante 硬约束）

来源详见 §附录。结论：中资入股美国 AI/芯片/自动驾驶/国防相关公司，经历三级跳。

| 时期 | 可投性 | 关键约束 |
|---|---|---|
| **2012–2017** | 宽松，基本进得去 | CFIUS 只管控制权收购；VC 少数股权基本不审。中国对美 FDI 2016 达峰约 $46B。红杉中国/IDG/ZhenFund 此期密集投中美 AI。 |
| **2018–2021** | 收紧，关键技术少数股权受限 | **FIRRMA**（2018.8 签署 / 2018.11 试点 / 2020.2 终规）把"非控股但有信息权/董事席位"的关键技术(TID)少数股权纳入 CFIUS 强制申报；中国从不在豁免国名单。强制剥离案例：Grindr/昆仑(2019)、StayNTouch/石基(2020)。中国 VC 对美投资 2019 年砍掉约 2/3。 |
| **2022–2024** | 前沿赛道对大陆资本实质性关闭；diaspora 美元基金 + 二级市场仍有缝隙 | 2022.10 对华芯片出口管制 + 2023.8 EO 14105（美投中三领域 AI/芯片/量子）形成脱钩信号。创始人为保政府合同/IPO 主动拒中资（Scale AI 切割 TikTok 合作、投资人全西方）。中国对美 FDI 较峰值降约 90%。**仍存缝隙**：华裔 GP 管理的美元基金、SPV/二级市场份额。 |

**Sourcing 推论：**
- 2018 后，**前沿大模型 / AI 芯片 / 自动驾驶 / 国防 tech** 这几类，大陆背景人民币/国资基金 ex-ante 就"够不着"——这些项目即便漏了，多半归 C 类（access），不是 sourcing 失败。
- 仍"够得着"的通道：① 2018 前的早期入场；② 应用层 SaaS/消费（非 TID）；③ 美籍华裔 GP / 美元 diaspora 基金；④ 二级市场。
